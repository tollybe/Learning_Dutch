# Learning Dutch: sustainable learning plan

Updated: 2026-11-09. Status: proposed for review.

## North star
Build confident and natural B1-to-B2 Dutch, with optional C1 and playful *onnodig bekakt* register exploration, without making language learning a second job.

## Non-negotiables
- **One daily word is enough.** Keep the existing 08:00 daily word.
- Keep the existing Wednesday and Saturday short B1 practice; do not add mandatory sessions.
- No streaks, penalties, catch-up debt, or requirement to report back.
- A day without Dutch is allowed. No guilt-based nudges.
- Learning is useful when Dutch becomes easier to use in real life, not when more documentation is created.
- AI handles the organisational workload; GitHub is the record, **not the learner's daily interface**.

## Modes: choose one, never stack them
| Mode | When | Practice | Approximate time |
|---|---|---|---|
| Minimum | Tired/busy day | Read the word and a natural example, or skip | 0–1 min |
| Everyday | Normal day | Read the word, say or write one sentence | 2–3 min |
| Rosie walk | Already walking Rosie | Optional audio/listening or one spoken sentence; no typing, reading, or screen attention while moving | 1–5 min within the walk |
| Curious | Have spare energy | Short B1 exercise, a dialogue, article, or Dutch media | 5–15+ min, optional |

**Walk mode safety:** Never look at the screen while moving, crossing roads, cycling, or handling Rosie. If audio is distracting or traffic is busy, skip it. Use only hands-free prompts and normal ambient awareness. A walk is still a walk—not a requirement to multitask.

## Practical weekly rhythm
- Every day: daily word at 08:00, as already scheduled.
- Wednesday/Saturday: short B1 practice, as already scheduled. It may replace—not supplement—the word's active exercise.
- Sunday: automatic GitHub vocabulary archive as already intended; learner review optional.
- When appropriate: one informal sentence with Daan, a Dutch friend or family member, **only if they want to participate**.

## Resource roles
- **Daan (native speaker):** occasional, explicitly welcomed naturalness checks, a 30-second mini-conversation or one small correction. He is a partner, not a standing tutor.
- **Daan's parents/friends:** real-life interaction first; vocabulary opportunities arise naturally. No grading or homework expectation.
- **Dutch resources:** signs, short articles, audio, books, podcasts and existing interests. Long B2/C1 syntactic decomposition remains opt-in.
- **AI:** choose a low-effort prompt, explain nuances and corrections, detect recurring difficulties from voluntarily captured attempts, and maintain project records.

## Methodology
1. Present a practical word or collocation in natural Dutch, with word class, relevant plural/conjugation/preposition and an everyday sentence.
2. Offer exactly one tiny active task, such as “say a sentence about today”, ideally reusable during a Rosie walk.
3. Distinguish recognition, prompted production, spontaneous use and delayed reuse; never infer mastery from exposure alone.
4. Prefer comprehensible, contextually appropriate Dutch to performatively complex sentences. Show any posh alternative as a separate, playful register.
5. For corrections, explain the most useful issue first, acknowledge valid alternatives, and avoid over-correcting.
6. Retry an expression later in a new context when useful; no compulsory review queue.
7. Keep personal conversations and voice transcripts out of a public repository unless explicitly approved.

## Evaluation
Monthly (optional): “Is the daily word still enjoyable?”, “Where did Dutch feel more natural?”, “Is any part burdensome?”. Track only verified, consented evidence. If the system adds friction, simplify it before doing more.
